> 状态：待架构师修订完成后合并进架构设计 v1.1

## C1 · Win10 及以上一键运行

| 项 | 要求 |
|---|---|
| 运行环境 | **Windows 10 及以上**（原 PRD 写 Win11+，需下调） |
| 交付形态 | 单个 `.exe`，双击即运行，**用户机器无需安装 Python** |
| 前置条件 | 无。不需要用户装依赖、配环境变量、开命令行 |
| 验收 | 在干净的 Win10 机器上双击 exe → 界面正常弹出 → 能完成一次跑批 |

**待架构师核查**：
- PySide6（Qt6）对 Win10 的最低版本要求（Qt 6.x 官方支持 Win10 1809+）
- PyInstaller 在 Win10 上的打包注意事项
- 是否有 Win11 专属 API 需替换

## C2 · 规则解耦（可快速迭代）

| 项 | 要求 |
|---|---|
| 诉求 | 后续**补充识别规则**时，能快速迭代，不用改动核心逻辑 |
| 现状 | 规则集中在 `core/constants.py` / `element_parser.py` / `noise_guard.py` |
| 待评估 | 是否将规则**外置为配置文件**（如 `rules/*.yaml`），改规则=改配置而非改代码 |
| 约束 | 外置的是规则的**实现载体**，**口径语义不得改变**（仍需与 SOP v2.0 一致） |
| 验收 | 新增一条"字段名黑名单"或"品牌正则"不需改 Python 代码，且回归测试仍全绿 |

**待架构师给出**：配置文件格式、加载时机、是否热加载、回归测试如何覆盖。

---

## C3 · 操作尽量简单

| 项 | 要求 |
|---|---|
| 原则 | 从双击 exe 到拿到结果，步骤最少化 |
| 候选优化 | 路径记忆（上次 Excel/图片/输出目录回填）、默认输出目录、上次配置复用 |
| 验收 | 第二次使用时，用户无需重新选全部路径即可开跑 |

## C4 · 断点续跑 UI（新增需求，推翻原 Q1 结论）

> 原架构设计 Q1 建议"静默续跑 + 日志提示，不做 UI"，**现按用户要求改为显式交互**。

### C4.1 交互要求

| 场景 | 要求 |
|---|---|
| 启动/选定数据源后 | **检测是否存在未完成的断点** |
| 存在断点时 · 开始按钮 | 文案变为「**重新开始**」（语义：清空断点，从头跑） |
| 存在断点时 · 暂停按钮 | 文案/状态体现为「**继续执行**」（语义：从断点续跑） |
| 存在断点时 · 预检通过位置 | **用红色文字**标识断点状态 |

### C4.2 红字文案模板（待架构师确认）

```
⚠ 检测到未完成断点：已完成 23/64 条（上次中断于 12:15），可点「继续执行」从断点续跑
```

### C4.3 防串票校验（关键）

断点必须与当前数据源绑定，**不能跨票误用上一个断点**。待架构师明确的绑定规则：
- 对比票号？
- 对比 Excel 路径 / 内容 hash？
- 对比图片目录路径？

> ⚠️ 这条直接关系"防错跑上一票"（README 6.1 已列为高危现象）。

### C4.4 验收

- 跑批中途强制关闭 → 重启选中同一票 → 开始按钮显示「重新开始」、暂停按钮显示「继续执行」、预检行红字提示断点进度
- 点「继续执行」→ 不重算已完成记录
- 点「重新开始」→ 清空断点从头跑
- 换一票 → **不得**误用上一票的断点

## C5 · 共享文件夹全支持（文件 + 目录均可 UNC）

| 项 | 要求 |
|---|---|
| Excel | 也要支持 UNC 路径（不只是图片目录） |
| 图片目录 | 支持 UNC，示例根：`\\172.20.99.220\制造中心\仓储物流部\成品科\{年份}年报关要素图片\` |
| 注意 | **`{年份}` 是变量**，跨年必须改（SOP 2.6「迁移必改三处」之一） |

**待架构师明确**：
- 用户给的这段路径是"图片根目录"，其下还要按 `{人员}\{票号}\` 查找 → 确认层级解析规则如何对应
- `QFileDialog` 选 UNC 文件/目录的兼容性坑
- `{年份}` 在 GUI 里的呈现方式（下拉选择？还是让用户直接选到票号目录？）
- 共享盘可达性探测与断连处理（原 R9）是否需强化

### 验收

- Excel 放在 UNC 上能正常读取
- 图片根目录填 UNC 能正常匹配
- 共享盘不可达时给明确报错（含路径），不中途崩溃

---

## 三条不变红线（重申，不受本次补充影响）

1. **原始输入只读** —— 不得写入/改名/移动/删除用户选定的 Excel 与图片目录
2. **产物分流** —— 交付物进「成果产出」，过程文件（JSON 日志/断点）进「过程产出」
3. **不虚高** —— 疑似 OCR 噪声不得直接上报为异常，必须提供看图确认入口
