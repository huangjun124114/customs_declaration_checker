## 三、与规格 §8.2 的偏差（重点复核）

### 偏差 1：seq=5 实测 ❌，规格期望 ✅ —— 根因定位（新发现，需裁决）

- **申报** `baori`；**规格依据**（§8.2）：「`无品`→none + `baori` 一致 → SOP 3.4 规则① → ✅」。
- **实测**：离线取 `NMY`、真 OCR 取 `EMV`（均 FAIL）。
- **根因（逐层 dump 定位）**：
  1. 品牌真实证据 `baori` 出现在 **img &004（产品图）** 的裸 token 行（`baori` 整行）+ `baori E339609 AWM…` 行；
  2. 但 `baori` 裸 token **只出现在 1 张图** → 触发 ④ 层「≥2 图一致」约束 → **被拒**（返回空）；
  3. 同时 **③ 品牌+型号行**（`min_images=1`）误捕了 **PCB 丝印残片** —— 离线 `NMY  809663`→`NMY`、真 OCR `EMV`；
  4. ③ 层一旦有候选即抢占（优先级 ③>④），把它当品牌 → 与 `baori` 不一致 → **❌**。
- **关键缺口**：`rules/non_brand_tokens.yaml`（元件厂标/丝印残片词表）**仅对 ④ 裸 token 层生效**；
  **③ 品牌+型号行层无 `non_brand` 过滤** → PCB 残片（`NMY`/`EMV`，同类 `NFK`/`SAMYOUNG`/`ONEL`）可穿透。
- **性质**：与 §4.3「元件厂标必须外置到 `non_brand_tokens.yaml`」的**规格意图**一致，但 §4.2 把该词表**明确限定于 ④ 裸 token 层**。
  → **属规格边界问题，不自作主张改口径**，请裁决。
