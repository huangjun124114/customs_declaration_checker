# ── 报关申报要素自动校验工具 · 运行时依赖（requirements.txt）──
# 版本按架构设计 v1.2 第 13.6 节「2026-09 环境实测锁定」照抄，禁止随意上调/下调。
#
# ⚠️ 安装务必走 tools/install_deps.py（推荐）或按下面三步手工执行：
#   1) pip install --no-cache-dir -r requirements.txt
#   2) pip uninstall -y opencv-python                 # rapidocr 会强拉非 headless 版，必须摘掉
#   3) pip install --no-cache-dir --force-reinstall --no-deps opencv-python-headless
#   最后用 tools/check_env.py 验环境（exit 0 才允许打包）
#   ⚠️ 禁止使用 --no-deps 安装主依赖（会破坏依赖树完整性）
#
# 【为什么必须做第 2、3 步】rapidocr 的元数据里写死 Requires-Dist: opencv_python>=4.5.1.48，
#   与我们要用的 opencv-python-headless 同装会争抢同一个 cv2/ 目录，后装者胜出 →
#   若被非 headless 版覆盖，会把自带 Qt DLL 塞进 exe，与 PySide6 冲突（双 Qt 崩溃）。
#   该冲突无法用 pip 的 resolver 表达（两者包名不同），只能装完后手工纠正。
